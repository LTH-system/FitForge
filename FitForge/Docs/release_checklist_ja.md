# リリースまでに必要な作業（利用者側）

公開後の修正1〜3と、有料プラン（フェーズA〜D）をリリースするために、Mac・Apple Developer・App Store Connect で行う作業です。上から順に進めてください。

## 1. こちらに教えてほしいもの

| 内容 | 理由 |
|---|---|
| プライバシーポリシーのURL | プレミアム画面のリンクが仮のURL（example.com）のまま。審査でアプリ内のリンクが必須 |
| ビルドで出たエラーの全文 | 開発環境にXcodeがなく、ビルドできていないため。エラーがあれば直します |

## 2. Xcode（Mac）

1. ブランチ `claude/amazing-mendel-6mcl8s` を取得してビルドする
2. FitForge ターゲット → Signing & Capabilities
   - ＋Capability → **iCloud**：Services の **CloudKit** にチェック、Containers に `iCloud.com.fitforge.app` を追加（なければ＋で作成）
   - ＋Capability → **In-App Purchase**
   - HealthKit は設定済み
3. バージョンを上げる：`Resources/Info.plist` の `CFBundleShortVersionString`（現在 1.0）を公開中のバージョンより大きく、`CFBundleVersion`（現在 1）も上げる
4. シミュレータで課金を試す：Product → Scheme → Edit Scheme → Run → Options → StoreKit Configuration で `FitForge.storekit` を選ぶ

## 3. iCloud（CloudKit）

1. iCloudにサインインした実機で開発ビルドを起動し、マイページ →「今すぐバックアップ」を1回実行する（開発環境に `Snapshot` の型が作られる）
2. CloudKit Console（icloud.developer.apple.com）→ `iCloud.com.fitforge.app` → **Deploy Schema Changes** で本番環境に反映する
   - これをしないと、App Store版ではバックアップに失敗します

## 4. App Store Connect

1. **有料アプリ契約**（ビジネス → 契約）が有効か確認。口座・税務情報の登録が必要
2. アプリ → **サブスクリプション** でグループ「FitForge プレミアム」を作り、2つ登録する

   | 製品ID | 期間 | 価格 | お試し |
   |---|---|---|---|
   | `com.fitforge.app.premium.monthly` | 1ヶ月 | 480円 | 導入オファー：無料・2週間 |
   | `com.fitforge.app.premium.yearly` | 1年 | 4,980円 | 導入オファー：無料・2週間 |

   - 480円・4,980円が選べる価格にあるか確認（なければ近い価格で。アプリは設定された価格をそのまま表示します）
   - 各製品に日本語の表示名・説明、審査用スクリーンショット（プレミアム画面）を登録
3. アプリの説明文の最後に、次の内容を書く
   - 自動更新サブスクリプションであること、価格と期間、2週間の無料お試し、解約方法（設定 → Apple ID → サブスクリプション）
   - 利用規約：`https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`
   - プライバシーポリシーのURL
4. **Appのプライバシー**（栄養ラベル）の内容を確認する
   - バックアップは利用者本人のiCloud（開発者は見られない）、課金はApple経由、バーコード照会で送るのは商品のバーコード番号のみ
5. 新しいバージョンを作成し、**サブスクリプション2つを同じ審査に含めて**提出する（初めてのサブスクリプションはアプリの新バージョンと一緒に審査されます）
6. 審査メモの例：「マイページ先頭の『FitForge プレミアム』から購入画面を開けます。記録機能はすべて無料で、長期の分析・部位別の量・栄養の過不足・次回の重量提案・ルーティン無制限・CSV書き出し・大会プランが有料です。」

## 5. 実機での確認

| 機能 | 確認すること |
|---|---|
| ヘルスケア同期 | 何度同期しても、体重グラフに同じ日の点が増えない |
| 起動時の記録 | 食事の時間帯を変えて、アプリを終了して開き直しても残っている |
| iCloudバックアップ | バックアップ後にアプリを削除して入れ直すと、起動時に復元の確認が出て記録が戻る |
| 課金 | 購入・無料お試し・購入の復元・サブスクリプションの管理（Sandboxのテストアカウントで） |
| プレミアム機能 | 未登録では案内カード、登録後は各機能が表示される（進捗・筋トレ・食事・マイページ・ラン） |
| CSV | ExcelやNumbersで開いて文字化けしない |
| ランの取り込み | Apple Watchなどのランが取り込まれ、同じランが二重にならない。削除したランが戻ってこない |
| ルーティン | 無料で3個まで作れ、4個目でプレミアムの案内が出る。ワークアウト画面で種目を順番に記録できる |
| シェア | 自己ベスト・大会（種類を race で記録）の結果画面から画像でシェアできる |
| 大会プラン | 大会日を入れると今週のメニューが出て、種類を合わせて記録すると完了になる |

# FitForge 開発プラン（UIモック反映版）

UIモック（ホーム、記録シート、目標逆算、食事、写真AI、筋トレ、自己ベスト、週次ふりかえり）のうち、未実装の機能を実装するための計画。

## 決定済みの方針

| 項目 | 決定 |
|---|---|
| タブ構成 | 今日・食事・＋・トレーニング・進捗。筋トレと運動は「トレーニング」に統合。マイページ（設定・目標編集・HealthKit）は今日タブ右上の歯車から開く |
| 予算の土台 | オンボーディングで性別・年齢・身長を聞き、Mifflin-St Jeor式で基礎代謝を計算。HealthKitの基礎代謝の実測があればそちらを優先 |
| 筋トレ記録 | 既存の「重量×回数×セット」形式は残し、新しい記録からセット単位で保存。グラフと自己ベストは両方の形式から計算 |
| 写真AI・食品DB | 後回し。サーバーの方針が決まってから着手。写真ボタンは仮置きのまま |
| 配色 | `Theme.swift` のライト／ダーク定義に従い、iPhoneの設定で自動切り替え |

## こちらで置いた前提（違えば変更）

- 減量ペースは「週0.25／0.4／0.5kg」の3段階。0.5kgを上限にする（仕様書の「急激な減量を推奨しない」に合わせる）
- 1日の予算の下限は、そのユーザーの基礎代謝量にする。目標ペースだと基礎代謝を下回る場合は、予算を基礎代謝に合わせ、そのペースで届く到着予定日を表示する
- 予算は1日ごとに固定し、運動した分を予算に足すことはしない。見積もりのずれは毎週の自動補正で吸収する
- 活動係数はオンボーディングの「週の運動回数」から決める（0〜1回:1.2、2〜3回:1.375、4回以上:1.55）
- 連続記録は、週2日までは休んでも途切れない
- 食事の時間帯は記録時刻から自動で振り分ける（〜10:59 朝食、11:00〜14:59 昼食、15:00〜16:59 間食、17:00〜 夕食）。記録後に変更できる
- 筋トレの消費カロリーは、セッションの時間 × 体重 × METs 5.0 で見積もり、消費カロリーに加算する

## 進め方

- 1項目ずつコミットし、ブランチ `claude/amazing-mendel-6mcl8s` にプッシュする
- 開発環境にXcodeがないため、ビルドと実機での確認はMac側で行ってもらう。フェーズごとに確認項目を渡す
- 計算ロジック（予算、消費、連続記録、自己ベスト）は画面から切り離した型にする。テスト用のターゲットはXcodeで追加してもらえれば、テストも書く
- データの形式を変えるときは、既存データが読めるようにする（JSONは `decodeIfPresent`、SwiftDataは初期値付きで項目を追加）。App Store公開後の利用者のデータを壊さない

| # | 内容 | 状態 |

| 修正3 | 英語切り替えを外し、日本語専用として整理する | 実装済み |

### iCloudバックアップを動かすためのXcode・Apple Developer側の作業

1. Xcodeで FitForge ターゲット → Signing & Capabilities → ＋Capability → iCloud を追加し、Services の CloudKit にチェック、Containers に `iCloud.com.fitforge.app` を追加（なければ＋で作成）。エンタイトルメントファイルには記述済み
2. 実機（iCloudにサインイン済み）で開発ビルドを起動し、マイページの「今すぐバックアップ」を1回実行する。これで開発環境に `Snapshot` レコード型が作られる
3. CloudKit Console（icloud.developer.apple.com）で、該当コンテナのスキーマを「Deploy Schema Changes」で本番環境へ反映する。これをしないとApp Store版ではバックアップに失敗する
4. 確認：アプリを削除して入れ直し、起動時に「iCloudにバックアップがあります」と表示され、復元できること

### App Store Connect・Xcode側の作業

1. App Store Connect → アプリ → サブスクリプション で、グループ「FitForge プレミアム」を作り、次の2つを登録する
   - `com.fitforge.app.premium.monthly`：期間1ヶ月、価格480円
   - `com.fitforge.app.premium.yearly`：期間1年、価格4,980円
2. それぞれに「お試しオファー（導入オファー）」を追加：無料・2週間
3. 表示名・説明、審査用のスクリーンショット（プレミアム画面）を登録する
4. 「有料アプリ契約」が有効か確認する（未締結だと課金できない）
5. `PremiumStore.privacyPolicyURL` を、登録済みのプライバシーポリシーのURLに置き換える（審査でアプリ内のリンクが必須）
6. アプリの説明文の最後に、自動更新の内容と利用規約・プライバシーポリシーのリンクを書く
7. シミュレータで試すとき：Xcode → Product → Scheme → Edit Scheme → Run → Options → StoreKit Configuration で `FitForge.storekit` を選ぶ
